# SpringShop Commerce

**SpringShop Commerce** is a modular e-commerce platform built with Java, Spring Boot, and microservice architecture principles.

## 🔧 Architecture

- **Modular microservices**: Each domain (product, order, inventory, etc.) is isolated.
- **Spring Boot + Maven Multi-module**
- **Dockerized** for local development
- **(Optional)** Front-end in Next.js

## 📦 Services

- Product Service
- Order Service
- Inventory Service
- Payment Gateway (planned)
- Notification Service (planned)

git clone https://github.com/erika-dev/springshop-commerce.git
cd springshop-commerce
